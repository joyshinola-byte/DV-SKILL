**TASK 9**

**House Sales Data Understanding, Cleaning & Feature Engineering**


**Objective**

To analyze real estate data, extract useful features, compare property valuation metrics, and 
identify outliers using Python.

**Tasks Performed**

**1. Inspect Property Features**

- Examined bedrooms, bathrooms, living area, grade, and year built.
- Checked dataset information, data types, missing values, and duplicates.
- Generated statistical summaries.

**2. Extract Temporal Attributes**

- Extracted Sale Year from sales dates.
- Calculated Property Age.
- Created Is Renovated to identify renovated properties.

**3. Compare Unit Valuation Metrics**

- Calculated price per square foot using property price and living area.
- Compared property valuation metrics using a bar chart.

**4. Outlier Analysis**

- Identified unusual property prices using the IQR method.
- Visualized outliers using a box plot.

**Tools and Libraries**

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

**Conclusion**

This analysis helps understand property features, calculate valuation metrics, 
identify renovation status, and detect unusual property prices.
