**Healthcare Data Visualization**

**Project Description**

This project focuses on healthcare data analysis and visualization using Python. 
It helps understand patient demographics, admission urgency, billing amounts, and hospital stay duration.

**Objectives**

Segment patient demographics based on medical conditions.

Clean missing values in medical condition data and standardize date attributes.

Categorize hospital admissions into Emergency, Elective, and Urgent.

Calculate summary statistics for patient billing amounts and hospital stays in days.

**Tools and Technologies**

Python

Google Colab

Pandas

NumPy

Matplotlib

**Dataset**

The healthcare dataset contains patient details, medical conditions, admission types, admission dates,
discharge dates, and billing amounts.

**Data Processing**

Loaded the healthcare dataset using Pandas.

Handled missing medical condition values.

Converted admission and discharge dates into a standard date format.

Calculated hospital stay duration in days.

**Data Visualization**

Bar chart showing patient count by medical condition.

Bar chart showing admission count by urgency category.

**Statistical Analysis**

Calculated count, mean, standard deviation, minimum, and maximum billing amounts.

Calculated summary statistics for hospital stay duration.

**Conclusion**

This project helps understand patient demographics, admission patterns, billing amounts, and hospital stay duration.
The results can support healthcare cost analysis and provide insights for healthcare planning and policy decisions.
